## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues for `Jenlybein/vision-smash-code`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels are used as-is (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` plus `docs/adr/` for ADRs. See `docs/agents/domain.md`.
